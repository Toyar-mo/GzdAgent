Crypto - RC4流密码

## 题目分析
题目使用RC4流密码算法加密flag，密钥为`love`，加密后的密文以列表形式给出。解密后得到hex编码的flag，需要进一步解码。

## 解题思路
1. 信息收集
   - 题目给出加密脚本和密文
   - 密钥为`love`，算法为标准RC4

2. 漏洞分析
   - RC4为对称流密码，加密和解密使用相同算法
   - 已知密钥和密文，可直接解密

3. 漏洞利用
   - 使用标准RC4算法，以`love`为密钥解密
   - 解密后得到数字列表：`[68, 65, 83, 67, 84, 70, 123, 114, 99, 52, 95, 105, 115, 95, 101, 97, 115, 121, 125]`

4. Flag获取
   - 将数字列表转换为ASCII字符，得到flag

## Payload
```python
flag = [164, 34, 242, 5, 234, 79, 16, 182, 136, 117, 78, 78, 71, 168, 72, 79, 53, 114, 117]
t = flag
N, K, S = [256, [0]*256], [0]*256, [i for i in range(256)]
key = 'love'
for i in range(256):
    S[i], K[i] = i, ord(key[i % len(key)])
j = 0
for i in range(256):
    j = (j + S[i] + K[i]) % 256
    S[i], S[j] = S[j], S[i]
i, j = 0, 0
for k in range(len(t)):
    i = (i + 1) % 256
    j = (j + S[i]) % 256
    S[i], S[j] = S[j], S[i]
    t[k] ^= S[(S[i] + S[j]) % 256]
print(t)
# [68, 65, 83, 67, 84, 70, 123, 114, 99, 52, 95, 105, 115, 95, 101, 97, 115, 121, 125]
# DASCTF{rc4_is_easy}
```

## Flag获取方式
直接运行题目给出的RC4加密脚本对密文再加密一次（RC4加解密相同），将结果数字列表转ASCII得到flag。

## 技术总结
关键词：RC4, 流密码, 对称加密, KSA, PRGA

核心要点：
1. RC4是流密码，加密和解密使用完全相同的过程
2. RC4算法分为KSA（密钥调度）和PRGA（伪随机生成）两个阶段
3. XOR运算的特性：密文再次异或相同密钥流即可还原明文
4. 密钥较短时，RC4安全性依赖密钥调度算法
