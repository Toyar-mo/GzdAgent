# Code share - 源码查看签到题

## 来源
CTF比赛: 2026年广东省大学生计算机设计大赛"网络与数据安全挑战赛"决赛
年份: 2026

## 类型
Web - 信息泄露 / 前端源码泄露

## 题目分析
签到题，flag直接写在前端HTML源码中，查看页面源代码即可获取。

## 解题思路
1. 信息收集
   - 访问目标页面

2. 漏洞分析
   - 查看页面源码（Ctrl+U），发现flag直接写在HTML注释或隐藏元素中

3. 漏洞利用
   - 使用浏览器开发者工具或Ctrl+U查看页面源代码

4. Flag获取
   - 源码中直接包含flag

## 使用工具
- 浏览器开发者工具 / Ctrl+U

## Payload
无（直接查看源代码）

## Flag获取方式
在目标页面使用Ctrl+U查看源代码，flag直接写在HTML源码中。

## 技术总结
关键词：前端信息泄露, 源码查看, 签到题

核心要点：
1. 前端源码中不能存放敏感信息
2. 查看源代码是最基本的Web信息收集手段
3. HTML注释、隐藏元素中可能包含flag
